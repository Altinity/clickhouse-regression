## Code-only line (contracts unrecoverable from code)

The following must be treated as **unknown** by the other 38 audits. Each is anchored, and each is unrecoverable specifically because the code is self-consistent in more than one reading.

1. **Wire-format compatibility window / downgrade promise.** `Formats/CasFormat.cpp:19-75` holds a complete per-format `changePoints` table that nothing calls, while `Formats/CasTextFormat.cpp:257`, `Formats/CasRecordStreamFormat.cpp:106`, and `Formats/CasBlobEnvelopeFormat.cpp:102` stamp `G_BUILD` (= 9, `Formats/CasFormat.h:10`) on every object. 2. **Retired-`FormatId` reuse policy.** `Formats/CasFormat.h:24-44` enumerates `FormatId` with deliberate gaps at 2, 3, 4, 6, 7, 10, 15. Unknown: whether those IDs are burned forever (retired formats that old readers may still encounter) or free for reuse.
